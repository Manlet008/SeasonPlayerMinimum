# Serene Seasons: Player Minimum

A companion mod for [Serene Seasons](https://www.curseforge.com/minecraft/mc-mods/serene-seasons) that adds a `seasonCyclePlayerMinimum` gamerule, letting you freeze season progression whenever fewer than a configured number of players are online.

## Usage

```
/gamerule seasonCyclePlayerMinimum <count>
```

## Server Properties
There's also some server settings for server admins, mostly about logging when the player count is met or unmet - but also the option to send a message to the chat letting them know that seasons are advancing or not, as well as how often those messages should be sent.


## Compatibility

- Works standalone against stock Serene Seasons.
- Works with [Serene Seasons Fix - Revived](https://www.curseforge.com/minecraft/mc-mods/serene-seasons-fix-revived).

## Installation

It's a mod, slap it in your mods folder.
